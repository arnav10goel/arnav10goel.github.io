This post is a draft, so it will not appear on the site until you change draft: true to draft: false in the frontmatter above. It exists to show you what the formatting looks like. Delete it once you have written something real.

To write a post, drop a file in posts/ named YYYY-MM-DD-your-slug.md and run python3 build.py. The URL comes from the slug, so this file would publish to /blog/example-post/.

Code

Fenced blocks are syntax-highlighted at build time, so there is no JavaScript involved and the colours follow light and dark mode:

def sample(model, prompt, temperature=0.7, max_tokens=256):
    """Greedy-ish decoding with a temperature knob."""
    tokens = model.tokenize(prompt)
    for _ in range(max_tokens):
        logits = model(tokens)[-1] / temperature
        tokens.append(logits.softmax(-1).multinomial(1))
        if tokens[-1] == model.eos_id:
            break
    return model.detokenize(tokens)

Math
